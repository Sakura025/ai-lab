# Phase 3 · 强化学习（★主线核心，前置：Phase 2 三件套齐）

> 具身智能的心脏。前面所有阶段（数据手感、网络基础）都为这一步服务。
> 学完这阶段，你从「会训练网络」变成「会训练会决策的智能体」。

## 学习地图（顺序固定）

1. **RL 全景直觉**：智能体/环境/状态/动作/奖励/回报——没有数据集，靠试错学
   - 数学按需补：期望、回报与折扣因子（未来的奖励今天值多少）
2. **gymnasium 交互循环**：`reset()` → `step(action)` → `obs, reward, done`——RL 版的「数据加载」
3. **CartPole 从随机到站稳**：先写随机动作看多快倒 → 再写策略让它站住——第一个具身任务
4. **DQN（深度 Q 学习）**：网络给每个动作打分，选分数高的——连着你 Phase 2 的网络功底
   - 与 PyTorch 对照：训练循环骨架不变，数据从「数据集」变「环境交互」
5. **策略梯度（入门）**：直接学「怎么选动作」而不是「每个动作值多少」——与 DQN 对照理解两大流派
6. **TensorBoard**：把训练曲线画出来——reward 从 20 涨到 500 的那张图就是「学习」的形状

## 项目③ · RL 训练 + 可视化

**任务**：CartPole（或 LunarLander）用 DQN 训练到稳定达标，TensorBoard 曲线存档。
**可选加分**：换一个自己选的环境（gymnasium 官网挑，0 流量内置的优先）。

**验收标准**：
- [ ] 训练脚本跑通，最终平均回报达到该环境的常见达标线（以官方文档为准，不编数字）
- [ ] TensorBoard 截图/日志：奖励曲线爬升过程可见
- [ ] 三件套：代码 + GitHub 仓库 + 复盘博客（讲清「试错怎么变成学习」）
