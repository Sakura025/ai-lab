# Phase 2 · PyTorch 深度学习（前置：Phase 1 三件套齐）

> 目标：从「调包」进到「会写训练循环」——tensor、autograd、nn.Module 全部亲手写一遍，最后用 CNN 打下视觉地基。
> 学习时间自定；项目②完成即本阶段毕业。

## 学习地图（顺序固定，每步都是下一步的地基）

1. **tensor**：和 numpy 对照学（创建/形状/切片/广播/GPU 搬运 `.to('cuda')`）——迁移你在 Phase 0 学的 numpy
2. **autograd**：`requires_grad` / `backward()` —— PyTorch 帮你算梯度，但你要知道它在算什么
   - 数学按需补：链式法则（复合函数的导数怎么连乘）
3. **手写第一次梯度下降**：不借助任何模型类，纯 tensor + autograd 拟合 `y = wx + b`——「学习」的本质就是这几行
4. **nn.Module**：把上一步改写成标准写法（`__init__` 定义层 / `forward` 定义计算）
5. **训练循环骨架**：`loss.backward()` → `optimizer.step()` → `optimizer.zero_grad()` 三件套，背下来
6. **Dataset / DataLoader**：批喂数据
7. **CNN**：卷积是什么（扫描小窗口提特征）→ 池化 → 搭一个小型卷积网络

## 项目② · 手写数字 → 图像分类（两级跳）

**第一级 MNIST**（数字识别，约 60MB，**下载前报流量**）：
- 用 torchvision 自带接口下载
- 从全连接网络起步，跑通训练循环，验证集 ~97%+ 是常见水平（以实测为准）

**第二级 CIFAR-10**（彩色小图十分类，约 170MB，**下载前报流量**）：
- 同一个训练循环骨架，换 CNN
- 目标准确率 ≥70%（留出集）——达不到就调（层数/epoch/数据增强），调的过程就是学

**硬件提醒**：8GB 显存跑这两个绰绰有余；batch_size 从 128 起步，爆显存就减半。
